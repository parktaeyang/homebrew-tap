# homebrew-tap

Personal Homebrew tap by parktaeyang.

```sh
brew install --cask parktaeyang/tap/teleclip
```

| Cask | Description |
|------|-------------|
| [teleclip](https://github.com/parktaeyang/Teleclip) | Menu bar OCR that copies on-screen text to the clipboard |

`Casks/teleclip.rb` is updated automatically by the Teleclip release workflow.

The Teleclip build is self-signed and not notarized. See the cask caveats (`brew info --cask parktaeyang/tap/teleclip`) for the first-launch steps.
